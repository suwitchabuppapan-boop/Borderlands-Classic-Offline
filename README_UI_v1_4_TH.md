# Borderlands Classic Pre-Renewal — v1.4 incremental update

แพตช์นี้ต่อจาก **Borderlands UI v1.3f** โดยรวมงานตามลำดับ v1.3g → v1.3h → v1.4 และมีเฉพาะไฟล์ที่เพิ่ม/เปลี่ยน ไม่ใช่เกมเต็ม ไม่ต้องลงแพตช์ระหว่างทาง

## ติดตั้ง
1. **Export Save** จากเมนู Settings ของเกมก่อนเสมอ และสำรองโฟลเดอร์ v1.3f ทั้งโฟลเดอร์ไว้ด้วย
2. แตกไฟล์ ZIP นี้ลงใน **โฟลเดอร์เกม v1.3f** เดิม ให้แทนที่เฉพาะไฟล์ที่มีชื่อซ้ำ (รักษาโครงสร้าง `js/` และ `css/`). ไม่ต้องลบไฟล์อื่น
3. เปิด `START.bat` เดิมหรือ `index.html`; หากต้องย้ายโฟลเดอร์หรือเปลี่ยน origin/เบราว์เซอร์ ใช้ Import Save ที่ export ไว้
4. ZIP นี้ไม่รวม API Key ไม่แก้ Divine Pride Importer/Cache ไม่แก้ asset จาก Phieti หรือระบบเกมส่วนอื่น

## v1.3g — Save Integrity
- เวลาโหลดเซฟ สร้าง **กระเป๋าว่าง** ก่อนนำจำนวนไอเทมจากเซฟมาใส่ แทนการยึดกระเป๋าเริ่มต้นของตัวละครใหม่
- หากเซฟระบุยาเป็น 0 หรือไม่มีรายการยา จะ **ไม่เพิ่ม HP Potion 5 / SP Potion 3** กลับมาโดยอัตโนมัติ
- รองรับเซฟรุ่น 1 และ 2 เดิม, อุปกรณ์สวมใส่ และ hotbar เดิม; ไม่เปลี่ยน schema/key ของเซฟ
- หากเซฟเก่าถูกบั๊กเติมยาและถูกบันทึกทับไปก่อนหน้านี้ เกมไม่สามารถแยกจำนวนที่ได้มาจริงออกจากจำนวนที่ถูกเติมผิดได้ จึงไม่ลบยาจากเซฟเก่าโดยเดาสุ่ม

## v1.3h — Inventory และ Skill UI
- Inventory แสดง **กริดช่องไอเทม** เลือกช่องเพื่อดูรายละเอียด ชนิด จำนวน และคุณสมบัติ; ปุ่มใช้/ใส่/ขาย/ผูก Hotbar แสดงตามประเภทไอเทม
- Equipment อยู่แยกหน้าต่างเหมือนเดิม; เมื่อใส่/ถอดแล้วข้อมูลรีเฟรชตามระบบเดิม
- Skill เป็นการ์ดอ่านง่าย ระบุ Lv., ค่า SP, cooldown, เงื่อนไขก่อนเรียน และปุ่มเรียน/ผูก Hotbar
- Hotbar 1–9 ยังคงรองรับการใส่/ถอด/สลับ Skill และ consumable; ไม่เปลี่ยนรูปแบบเซฟของ hotbar

## v1.4 — Combat Core (สูตรประยุกต์ SOLO)
- HIT/FLEE ถูกใช้คำนวณโอกาสตีโดนทั้งฝั่งผู้เล่นและศัตรู; เมื่อโจมตีพลาดแสดง **MISS**, เมื่อผู้เล่นหลบสำเร็จแสดง **DODGE**
- Basic attack, Bash และ Magnum Break ใช้กระบวนการตรวจ HIT เดียวกัน; Auto Play เรียกระบบต่อสู้เดียวกับการกดเอง
- AGI และ DEX ส่งผลต่อช่วงเวลาโจมตีปกติ (attack interval); status แสดง HIT/FLEE, ASPD และวินาทีต่อครั้งแทนการล็อก 0.63 วินาที
- การหาค่า HIT/FLEE ผู้เล่นใช้ Base Lv + DEX/AGI; โอกาสโจมตีเบื้องต้น `80 + HIT - FLEE` เปอร์เซ็นต์ ภายใต้เพดานและค่าต่ำสุดของเกม SOLO
- **ไม่ใช่สูตร Ragnarok Pre-Renewal ครบทุกขั้น:** ค่ารอง AGI/DEX ของมอนสเตอร์ที่ฐานข้อมูลยังไม่มี, ช่วงโจมตีตามคลาส, การลด FLEE เมื่อศัตรูรุม และเพดานโอกาสตีโดน เป็นค่าประยุกต์ SOLO; ยังไม่มี weapon-specific delay/ASPD modifiers. ค่าสเตตัสอื่น ๆ ยังใช้สูตร SOLO เดิม

## ขอบเขตและการทดสอบ
- ไม่มี Sprite/Animation ใหม่, อาชีพใหม่, แผนที่ใหม่ หรือการดึงข้อมูล Divine Pride ไปแก้ค่าเกมโดยอัตโนมัติ (เป็นงาน v1.5 ขึ้นไป)
- มีชุดทดสอบ Node สำหรับ Save/Combat และชุด Chromium สำหรับ Inventory, Skill, Hotbar, Equipment, Save/Load จริงแบบ mock localStorage, MISS/HIT/DODGE และการแสดงผลหลายขนาดหน้าจอ
- การทดสอบในสภาพแวดล้อมจัดทำแพตช์ไม่สามารถเปิด URL `file://` หรือ localhost ผ่าน Chromium ได้เนื่องจากถูกบล็อก ดังนั้น **ไม่ได้ยืนยันการเปิดไฟล์โดยตรงบน Windows**; `START.bat` และการโหลดไฟล์ภายใน ZIP คงโครงสร้างเดิมไว้
- ชุดทดสอบ v1.3 เก่าบางชุดตรวจ HUD/Hotbar แบบเก่าก่อน Smart UI; อย่าใช้ผลนั้นตัดสิน UI ใหม่โดยไม่อัปเดตความคาดหวัง

**หมายเหตุ:** แพตช์เฉพาะไฟล์ต้องมีเกม v1.3f แบบเต็มที่ติดตั้งก่อนแล้ว ห้ามแตก ZIP เป็นเกมใหม่แยกเดี่ยว

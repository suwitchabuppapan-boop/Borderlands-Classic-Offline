# สยามอรุณ รุ่น 1.16

เกม RPG เล่นคนเดียวบนเว็บ บรรยากาศสยามแฟนตาซี เริ่มเป็นชาวบ้าน เปลี่ยนเป็น Class 1 ได้ 5 สาย และต่อยอดเป็น Class 2 รวม 10 สาย มี 3 แผนที่และเควสต์หลัก 3 บท

เล่น: https://suwitchabuppapan-boop.github.io/Borderlands-Classic-Offline/

รุ่นนี้เพิ่มเลขดาเมจพิกเซลขอบเข้ม คริพร้อมดาวกระแทกและคำว่า Critical!! รวมถึง Miss และ Lucky!! ตามผลโจมตีจริง แยกสีเลขกายภาพ เวทและความเสียหายที่ได้รับ จัดเลขหลายฮิตตามขอบเขตภาพให้ไม่ซ้อนกัน และจัดตำแหน่งให้ตรงกริดพิกเซลบนจอ

ลบไอเทมเก่า 2 ชิ้น สกิลเก่า 3 สกิล หมวดเก่าในหน้าคู่มือและสกิล รวมถึงการย้ายเซฟรูปแบบโบราณออกแล้ว

VFX แนวคลาสสิกครบอาวุธ 11 ประเภทและสกิลประจำสาย 15 สกิล ในแนวแฟนตาซีคลาสสิกสยาม ใช้ปื้นรอยฟัน แกนแสงงาช้าง กลีบบัว แก้วมณี อักขระและบ่วงนาคา แยกจังหวะปล่อย ปะทะ และสลาย พร้อมคริติคอล บัฟ ประจุ พิษและเลือดไหลที่เคลื่อนไหวตามเวลาจริงของสถานะ

หน้าสกิลยังแสดงเฉพาะอาชีพปัจจุบันกับสายต้นทาง และ Auto Battle / Auto Quest ยังฟาร์มต่อระหว่างเปิดเมนู สลับแท็บหรือย่อหน้าต่าง ค่าโจมตี SP คูลดาวน์และดรอปของเนื้อหาปัจจุบันใช้สูตรเดิม

## วิธีเล่น

- เดินด้วย WASD/ปุ่มลูกศร หรือคลิกพื้น คลิกมอนสเตอร์เพื่อเดินเข้าไปโจมตี
- Space โจมตี และปุ่ม 1–9 ใช้ Hotbar เปิดเมนูแล้วเกมยังฟาร์มต่อ
- เดินเข้าใกล้แม่บัวเพื่อซื้อขาย ครูอินให้เควสต์และเปลี่ยนอาชีพ หมอมะลิฟื้น HP/SP ฟรี
- Class 1 ต้อง Job 10 ส่วน Class 2 ต้อง Job 40 และทำบททดสอบของสายให้ครบ
- Auto Quest ใช้การเดินและต่อสู้จริง ควรเตรียมอาวุธ สเตตัสและยาก่อนเริ่ม
- Export Save ในหน้าตั้งค่าเพื่อสำรองเกม เก็บเซฟไว้ในเบราว์เซอร์ที่ใช้เล่น

ต้องเปิดหน้าเกมไว้เพื่อฟาร์มเบื้องหลัง หากเบราว์เซอร์พักแท็บหรือเครื่องหลับ ระบบจะคำนวณเวลาที่ค้างผ่านการต่อสู้จริงเมื่อกลับมา และให้รอก่อนสั่งงานระหว่างชดเชยเวลา การทำงานสดระหว่างพักแท็บขึ้นอยู่กับเบราว์เซอร์ การปิดหรือโหลดหน้าใหม่จะไม่แจกของจากเวลาออฟไลน์ และไม่เปิด Auto กลับเอง

ไอเทมมี 59 ชิ้น: หาได้จริง 42 ชิ้น และวางแผนไว้ 17 ชิ้น สกิลมี 16 สกิล: ประจำอาชีพ 15 สกิลและปฐมพยาบาล อาวุธ 11 ประเภทมีอย่างละ 3 ระดับ บอสและแหล่งดรอปที่ระบุว่า “เตรียมไว้” ในคู่มือยังไม่เปิดให้เล่น

## พัฒนาและทดสอบ

ไม่ต้องติดตั้ง npm หรือ build เกม ใช้ Python เปิด HTTP server จากโฟลเดอร์นี้:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ตรวจระบบด้วย `node --test tests/*.test.js` และตรวจเบราว์เซอร์ด้วย `python3 scripts/test_browser.py --base-url http://127.0.0.1:8765/ --artifacts /tmp/siam-browser` โดยต้องมี Python Playwright และ Chromium ดูคำสั่งแพ็กเว็บใน [scripts/README.md](scripts/README.md) และผลตรวจใน [TEST_RESULTS.md](TEST_RESULTS.md)

เซฟรูปแบบปัจจุบันต้องมีอาชีพ เวอร์ชันสเตตัสและช่องสวมใส่ครบ 4 ช่อง รายการไอเทม/สกิลที่ไม่อยู่ในเกมจะถูกตัดออกพร้อมปุ่มลัด โดยรักษาความคืบหน้าปัจจุบันไว้ เซฟโบราณที่ไม่มีอาชีพ เวอร์ชันสเตตัสหรือช่องหมวกใช้ไม่ได้ การเปิดไฟล์โดยตรงและ START.bat บน Windows ยังไม่ได้ตรวจบนเครื่อง Windows จริง

# สยามอรุณ รุ่น 1.17

เกม RPG เล่นคนเดียวบนเว็บ บรรยากาศสยามแฟนตาซี เริ่มเป็นชาวบ้าน เปลี่ยนเป็น Class 1 ได้ 5 สาย และต่อยอดเป็น Class 2 รวม 10 สาย มี 3 แผนที่และเควสต์หลัก 3 บท

เล่น: https://suwitchabuppapan-boop.github.io/Borderlands-Classic-Offline/

รุ่นนี้นำชุดสกิลที่ตกลงไว้เข้าเกมครบ 61 สกิล: สกิลใช้งานประจำอาชีพ 45 สกิล สกิลติดตัว 15 สกิล และปฐมพยาบาล พร้อม Effect Part 58 ชิ้นสำหรับประกอบภาพเอฟเฟกต์

Class 1 แต่ละสายมีสกิลใช้งาน 3 และติดตัว 1 ส่วน Class 2 เพิ่มอีก 4 สกิลและสืบทอด Class 1 หน้าสกิลแสดงเฉพาะสายปัจจุบัน บอกผล ค่า SP และคูลดาวน์ พร้อมปุ่มเรียน ใช้งานและตั้ง Hotbar สกิลติดตัวเรียนแล้วมีผลตามสายโดยไม่ต้องกดใช้

เพิ่มการโจมตีเป็นกรวย โจมตีชิ่งและทะลุ เกราะดูดซับ ตราบนเป้าหมาย การเคลื่อนที่และบัฟใช้ครั้งเดียวตามชุดสกิล Auto Battle เลือกสกิลที่เรียนตามเงื่อนไข ส่วน Auto Quest ยังใช้การเดิน ต่อสู้และรับรางวัลจริง เอฟเฟกต์ผูกกับผลโจมตีและเวลาสถานะจริง เลขดาเมจพิกเซล คริ Miss และ Lucky!! ยังคงอยู่

## วิธีเล่น

- เดินด้วย WASD/ปุ่มลูกศร หรือคลิกพื้น คลิกมอนสเตอร์เพื่อเดินเข้าไปโจมตี
- Space โจมตี และปุ่ม 1–9 ใช้ Hotbar เปิดเมนูแล้วเกมยังฟาร์มต่อ
- เดินเข้าใกล้แม่บัวเพื่อซื้อขาย ครูอินให้เควสต์และเปลี่ยนอาชีพ หมอมะลิฟื้น HP/SP ฟรี
- Class 1 ต้อง Job 10 ส่วน Class 2 ต้อง Job 40 และทำบททดสอบของสายให้ครบ
- Auto Quest ใช้การเดินและต่อสู้จริง ควรเตรียมอาวุธ สเตตัสและยาก่อนเริ่ม
- Export Save ในหน้าตั้งค่าเพื่อสำรองเกม เก็บเซฟไว้ในเบราว์เซอร์ที่ใช้เล่น

ต้องเปิดหน้าเกมไว้เพื่อฟาร์มเบื้องหลัง หากเบราว์เซอร์พักแท็บหรือเครื่องหลับ ระบบจะคำนวณเวลาที่ค้างผ่านการต่อสู้จริงเมื่อกลับมา และให้รอก่อนสั่งงานระหว่างชดเชยเวลา การทำงานสดระหว่างพักแท็บขึ้นอยู่กับเบราว์เซอร์ การปิดหรือโหลดหน้าใหม่จะไม่แจกของจากเวลาออฟไลน์ และไม่เปิด Auto กลับเอง

ไอเทมมี 59 ชิ้น: หาได้จริง 42 ชิ้น และวางแผนไว้ 17 ชิ้น สกิลมี 61 สกิล: ใช้งานประจำอาชีพ 45 ติดตัว 15 และปฐมพยาบาล ต้องใช้แต้มเรียนจึงใช้สกิลใหม่ได้ อาวุธ 11 ประเภทมีอย่างละ 3 ระดับ บอสและแหล่งดรอปที่ระบุว่า “เตรียมไว้” ในคู่มือยังไม่เปิดให้เล่น

## พัฒนาและทดสอบ

ไม่ต้องติดตั้ง npm หรือ build เกม ใช้ Python เปิด HTTP server จากโฟลเดอร์นี้:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ตรวจระบบด้วย `node --test tests/*.test.js` และตรวจเบราว์เซอร์ด้วย `python3 scripts/test_browser.py --base-url http://127.0.0.1:8765/ --artifacts /tmp/siam-browser` โดยต้องมี Python Playwright และ Chromium ดูคำสั่งแพ็กเว็บใน [scripts/README.md](scripts/README.md) และผลตรวจใน [TEST_RESULTS.md](TEST_RESULTS.md)

เซฟรูปแบบปัจจุบันต้องมีอาชีพ เวอร์ชันสเตตัสและช่องสวมใส่ครบ 4 ช่อง รายการไอเทม/สกิลที่ไม่อยู่ในเกมจะถูกตัดออกพร้อมปุ่มลัด โดยรักษาความคืบหน้าปัจจุบันไว้ เซฟปัจจุบันรุ่น 1.16 เพิ่มช่องสกิลใหม่เป็นระดับ 0 โดยรักษาความคืบหน้าและแต้มเดิม เซฟใหม่ระบุเวอร์ชันสกิล 2 เซฟโบราณที่ไม่มีอาชีพ เวอร์ชันสเตตัสหรือช่องหมวกใช้ไม่ได้ การเปิดไฟล์โดยตรงและ START.bat บน Windows ยังไม่ได้ตรวจบนเครื่อง Windows จริง

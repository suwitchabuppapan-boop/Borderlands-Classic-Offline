# สกิลนักดาบอรุณและดาบสองมือ — 1.21

ข้อมูลชุดนี้ใช้แทนสกิลนักดาบเดิม โดยอ้างอิงข้อความ Swordman ชุดใหม่ที่ผู้ใช้ส่งมา สกิล Class 1 สืบทอดไปยังขุนดาบราชันและพิทักษ์นคร สกิลประจำ Class 2 ยังมีระดับสูงสุด 5 และคงค่าพลังเดิม

การเรียนสกิลหลักใช้หนึ่งแต้มต่อระดับ ส่วนสามสกิลพิเศษไม่ใช้แต้มแต่ต้องอยู่ใกล้ครูอิน ระยะใกล้ครูอินใช้กติกาเดียวกับการเปลี่ยนอาชีพ ผังสกิลประเมินเงื่อนไขจากระดับทั้งหมดในแผน จึงจัดฟาดฟันรุนแรง 5 และระเบิดเพลิง 1 แล้วยืนยันพร้อมกันได้ การลดแต้มร่างที่ทำให้สกิลอื่นขาดเงื่อนไขจะถูกปฏิเสธ

## การทำงานร่วมกับระบบเดิม

- ความชำนาญดาบเป็นความเสียหายเพิ่มต่อฮิตหลังคิด DEF ไม่ใช่การเพิ่มค่า ATK ในหน้าสเตตัส และไม่ถูกคูณด้วยพลังสกิลหรือคริติคอล ส่วนโบนัสธาตุที่เกมรองรับยังมีผลกับความเสียหายนี้ เกมยังไม่มีระบบการ์ด จึงไม่ได้เพิ่มระบบการ์ดเพื่อสกิลนี้
- ฟาดฟันรุนแรงและระเบิดเพลิงใช้การตรวจ HIT จริงพร้อมโบนัสประจำระดับ ต่างจากสกิลเดิมที่รับประกันการโดน ระเบิดเพลิงเพิ่มโบนัสไฟหลังคำนวณการระเบิดครั้งนั้น ใช้กับการโจมตีกายภาพโดยตรงครั้งต่อไปและไม่ซ้อนทบตัวเอง
- การใช้สกิลมีช่วงรอท่าร่วม 0.45 วินาที การโจมตีปกติ 0.28 วินาที ระเบิดเพลิงหน่วงสกิลอีก 2 วินาที แต่โจมตีปกติได้หลังช่วงรอท่าร่วม ไอเทมและเมนูยังใช้ได้
- สายนักดาบหยุดฟื้น HP ตามธรรมชาติขณะเดินจนกว่าจะเรียนฟื้นฟูขณะเคลื่อนที่ ส่วน SP และการฟื้นฟูของสายอื่นคงเดิม โบนัสยืนนิ่ง 10 วินาทีแยกจากรอบฟื้นฟูพื้นฐาน 4 วินาที การเดินจริงจะเริ่มนับเวลายืนใหม่ และน้ำหนักตั้งแต่ 50% หยุดการฟื้นฟู
- ยืนหยัดป้องกันการชะงักของสายนักดาบ การโจมตีที่หลบได้ไม่หักจำนวนครั้ง การโจมตีที่ถูกเกราะดูดซับความเสียหายยังนับเป็นการโดนหนึ่งครั้ง ครั้งที่เจ็ดยังได้รับผลป้องกันการชะงักแล้วบัฟจึงหมด
- คลั่งอัตโนมัติเพิ่ม ATK และลดเฉพาะส่วนป้องกันพื้นฐานจาก VIT ไม่ลดเกราะหรือส่วนจาก AGI เมื่อ HP เท่ากับ 25% พอดีจะคงสถานะก่อนหน้า Auto Battle ไม่เปิดหรือปิดสวิตช์นี้ให้เอง ข้ามแผนที่ยังคงเปิดสวิตช์ไว้ แต่เมื่อตายหรือโหลดเซฟต้องเปิดใหม่

## จุดที่ปรับให้เข้ากับสยามอรุณ

ต้นฉบับระเบิดเพลิงระบุ HP 15 ในคำอธิบาย แต่ตารางรายระดับระบุ 20–16 รุ่นนี้ยึด **ตารางรายระดับ** และเหลือ HP อย่างน้อย 1 หลังใช้ ส่วนโอกาสมึนงงต้นฉบับไม่ได้ระบุสูตรโบนัส Base Level จึงกำหนดโบนัส **0.1 จุดเปอร์เซ็นต์ต่อ Base Level** และแสดงไว้ในรายละเอียดสกิล

เกมแปลงหนึ่งช่องเป็น 32 หน่วยภาพ พื้นที่ระเบิด 5×5 ช่องจึงเป็นสี่เหลี่ยมที่ห่างจากจุดศูนย์กลางได้ไม่เกิน 80 หน่วยต่อแกน และผลัก 64 หน่วย ระยะประชิดฟาดฟันรุนแรงใช้ระยะ 58 หน่วยตามระยะตัวละครเดิม ยั่วยุใช้ 288 หน่วย คูลดาวน์ฟาดฟันรุนแรง 2 วินาทีคงจากเกมเดิม เนื่องจากชุดข้อมูลใหม่ไม่ได้ระบุคูลดาวน์นี้

เกมเป็น single player จึงไม่มี PvP, War of Emperium หรือสนาม Turbo Track และยังไม่มีระบบนั่งหรือกับดักศัตรู เงื่อนไขเฉพาะระบบเหล่านั้นไม่ได้จำลองเพิ่ม

## สายดาบสองมือและเซฟเดิม

ผู้ใช้เลือกเปลี่ยนสายดาบคู่เป็นดาบสองมือ อาชีพใหม่แสดงชื่อ **ขุนดาบราชัน** โดยคงรหัสอาชีพ `royal_duelist` เพื่อรักษาความคืบหน้า รูปแบบอาวุธเปลี่ยนเป็น `two_hand_sword` และใช้ภาพตัวละครครบทั้งตัว 24 ท่าใน 4 ทิศทาง ไม่ประกอบแขนหรืออาวุธลอยแยกชิ้น

| รหัสไอเทมเดิมที่คงไว้ | ชื่อใหม่ |
| --- | --- |
| `palace_dual_blades` | ดาบใหญ่ราชวัง |
| `banyan_dual_blades` | ดาบใหญ่ไทรอาคม |
| `sun_royal_dual_blades` | ดาบใหญ่สุริยราชัน |

ราคา ค่าพลัง น้ำหนัก และแหล่งดรอปของไอเทมเหล่านี้คงเดิม สกิล Class 2 เปลี่ยนชื่อให้เข้ากับดาบใหญ่แต่คงค่าพลังเดิม

เซฟใหม่ใช้ `skillVersion: 3` ภายใต้คีย์บันทึกเดิม `borderlands-solo-rebuilt-v1` เมื่อนำเข้าเซฟ schema 2 หรือเซฟ 1.16 ที่รองรับ ระบบตรวจระดับและสิทธิ์อาชีพเดิมก่อนคืนแต้มเฉพาะสี่สกิลนักดาบเก่า รีเซ็ตสิบสกิลนักดาบใหม่เป็นศูนย์ และล้างช่อง Hotbar ที่ผูกสี่สกิลที่ถูกคืนแต้ม สกิล Class 2 เลเวล ไอเทม สเตตัส และความคืบหน้าคงอยู่ การโหลด schema 3 ไม่คืนแต้มซ้ำ สถานะชั่วคราว เช่น บัฟ สวิตช์คลั่ง ช่วงรอท่า และมึนงง ไม่ถูกบันทึก

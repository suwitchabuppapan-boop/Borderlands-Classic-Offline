# v1.5 — Sprite ที่นำเข้าจากภาพผู้ใช้

## ที่มา
- `PC _ Computer - Ragnarok Online - Classes (Male) - Novice(1).png`: Sprite Sheet ตัว Novice ชายที่ผู้ใช้อัปโหลด
- `PC _ Computer - Ragnarok Online - Heads (Male _ Original) - White(1).png`: Sprite Sheet ทรงผมชายที่ผู้ใช้อัปโหลด

แปลงไฟล์ 2 ภาพข้างต้นเป็น `assets/sprites/novice_ro_hair_00.png` ถึง `novice_ro_hair_18.png` (รวม 19 แบบ) โดยใช้ภาพหัวซ้อนบนภาพตัวตามทิศทางและเฟรมที่มีอยู่จริง ไม่มีการดึงไฟล์จากอินเทอร์เน็ตหรือ API ขณะเปิดเกม และไม่ต้องติดตั้ง Python สำหรับการเล่น

## โครงข้อมูลที่ Runtime ใช้
- หนึ่ง Atlas = 832 × 448 พิกเซล; หนึ่งเฟรม = 64 × 112 พิกเซล
- 4 แถว = down, left, right, up
- 13 ช่องต่อแถว: Idle 0–1, Walk 2–5, Attack 6–8, Hit 9, Death 10–12
- กำหนดขนาดแสดงผลใน Canvas = 42 × 74 พิกเซล; sprite วางเท้าชิดตำแหน่งตัวละคร
- Settings → ทรงผมตัวละคร: เลือกได้ 19 แบบสำหรับ Novice / Swordman ชาย; บันทึกลง Save และ Export Save พร้อมข้อมูลตัวละคร
- เซฟเดิมที่ไม่มี `hairStyle` ใช้แบบ 1 อัตโนมัติ

## ส่วนที่ยังไม่มีในภาพต้นทาง
- เพิ่มภาพ **Swordman ชาย** ที่ผู้ใช้อัปโหลดเพิ่มเติมแล้ว: `swordman_ro_hair_00.png` ถึง `swordman_ro_hair_18.png` (19 แบบ) · มอนสเตอร์ยังใช้ภาพที่สร้างใหม่ในโปรเจกต์
- ท่าต่าง ๆ ได้จากการจับคู่เฟรมใน Sprite Sheet ที่ส่งมา โดยเลือกมุมใกล้เคียงสำหรับบางท่า ไม่ใช่ระบบ Animation อย่างเป็นทางการของเกมต้นฉบับ
- ภาพ Sprite Sheet ต้นฉบับทั้งสามไฟล์ไม่ถูกรวมซ้ำเข้า ZIP เพราะแพตช์มีเฉพาะ Atlas ที่แปลงแล้ว

## วิธีติดตั้ง
แพตช์นี้ทำเพื่อแตกทับ **Borderlands Classic v1.4.2 เกมเต็ม** จากนั้นเปิด `START.bat` หรือ `index.html`. ZIP มีเฉพาะไฟล์ที่เปลี่ยนจาก v1.4.2 พร้อมไฟล์ Sprite ใหม่ ไม่มี EXE, API Key หรือ Python เป็นเงื่อนไขการเล่น

## สถานะการทดสอบ
- ทดสอบใน Chromium ผ่านการฝัง HTML, JS และภาพจากไฟล์ไว้ในหน้าเว็บเฉพาะการทดสอบ พร้อม LocalStorage จำลอง: เลือกทรงผม บันทึก/อ่านกลับ และเดินได้
- สภาพแวดล้อมทดสอบบล็อกการเปิด `file://` จึงยังไม่ได้ยืนยันการดับเบิลคลิกเกมบน Windows จริง

## สิทธิ์
ภาพ Novice, Swordman และทรงผมเป็นงานจากไฟล์ Ragnarok ที่ผู้ใช้อัปโหลด ไม่ใช่ Asset ที่โปรเจกต์สร้างใหม่ การได้รับไฟล์ไม่ได้ยืนยันสิทธิ์แจกจ่ายต่อ ใช้สำหรับเกมส่วนตัวและตรวจสอบใบอนุญาตของเจ้าของผลงานก่อนนำแพตช์ที่มีภาพเหล่านี้ไปเผยแพร่

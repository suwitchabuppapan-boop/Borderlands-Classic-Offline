# Borderlands UI v1.3f — Stable UI (เฉพาะไฟล์ที่เปลี่ยน)

**ฐานที่ต้องติดตั้งก่อน:** UI v1.3e (ซึ่งรวมไฟล์ v1.3d/v1.3c ที่จำเป็นไว้แล้ว)

## วิธีติดตั้ง
1. ปิดเกมและสำรองโฟลเดอร์เกม รวมถึง Export Save ไว้ก่อน
2. แตก ZIP ลงโฟลเดอร์เกมที่มี `index.html` แล้วเลือก Replace `js/game.js` เท่านั้น
3. เปิด `START.bat` ของเกมเดิม หรือ `index.html` ตามปกติ

## สิ่งที่แก้
- เมื่อเรียน Skill / เพิ่ม Stat / ซื้อหรือขาย Item / ใช้ Item / สวมและถอด Equipment: หน้าต่างปัจจุบันจะอัปเดตทันที ไม่ต้องรอรอบรีเฟรชถัดไป
- ป้องกันการรีเฟรชหน้าต่าง Auto Settings ระหว่างที่กำลังโฟกัส dropdown หรือช่องกรอกข้อมูล ทำให้เลือกค่าได้ต่อเนื่อง
- รักษา Auto Battle ใต้ Minimap, Hotbar 1–9 ที่กำหนดเอง, สกินจาก Phieti, การบันทึก/โหลด และ Divine Pride Importer เดิม โดยแพตช์นี้ไม่แก้ไฟล์เหล่านั้น

## ขอบเขตการทดสอบ
ผ่าน Core, Codex, Offline Static, browser UI/integration, Hotbar/Auto/Equipment, Save/Load แบบจำลอง storage ของเบราว์เซอร์, Export/Import และการจัดหน้าจอหลายขนาด

**ข้อจำกัด:** สภาพแวดล้อมทดสอบปิดกั้นการเปิด `file://` และ localhost จาก Chromium จึงยังไม่ได้ยืนยันการเปิดไฟล์โดยตรงบน Windows; โปรดทดลองด้วย `START.bat` บนเครื่องจริง แพตช์นี้ไม่ต้องใช้ API Key ขณะเล่นและไม่ได้รวม Key ใด ๆ

**ไฟล์เกมที่แก้จริง:** `js/game.js` เพียงไฟล์เดียว

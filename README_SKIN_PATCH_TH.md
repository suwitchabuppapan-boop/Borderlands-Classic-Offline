# Borderlands UI v1.3e — ใช้ภาพ Skin จริง (Patch เฉพาะไฟล์เปลี่ยน)

ฐานที่ต้องมี: Borderlands UI v1.3d ติดตั้งแล้ว

วิธีติดตั้ง: สำรองโฟลเดอร์เกม จากนั้นแตก ZIP นี้ลงโฟลเดอร์เกมแล้วเลือกทับไฟล์ `css/style.css` และรวมโฟลเดอร์ `assets/phieti/` ในตำแหน่งเดิม ห้ามแตกแยกไว้คนละชั้นกับ index.html

เปลี่ยนเฉพาะ CSS และภาพ PNG 10 ไฟล์; ไม่มีการแก้ index.html หรือ JavaScript จึงรักษา Auto ใต้ Minimap, Hotbar 1–9, Save และตัวนำเข้าข้อมูล API เดิม

ภาพทั้ง 10 เป็นการแปลงชิ้นส่วน BMP จาก Phieti.zip ที่ผู้ใช้อัปโหลดเป็น PNG โดยตั้งพิกเซลสี magenta (#FF00FF) เป็นโปร่งใส เช่น พื้น HUD, หัวหน้าต่าง, สกินช่อง Hotbar, พื้น Equipment/Status และปุ่มเมนู 4 ชนิด

ROSkinViewer3.0-1.zip ตรวจเพื่อศึกษาตำแหน่งและสัดส่วน แต่ BMP เช่น Tmain, Tequi, Tstats และ TShortback เป็นภาพตัวอย่างที่มีข้อความ/ตัวเลข/ไอเทมฝังลงบนภาพและพื้น magenta จึงไม่ฝังตรงเป็นหน้าต่างที่แสดงสถานะเปลี่ยนตามเกม เพราะข้อมูลจะซ้อนและไม่สามารถอัปเดตเป็นค่าเกมจริงได้

สิทธิ์การใช้/แจกจ่ายภาพใน ZIP ต้นทางไม่ได้มีเอกสารยืนยัน จึงเตรียมไว้สำหรับใช้งานส่วนตัวในเกม Offline ของผู้ใช้ และไม่อ้างสิทธิ์ในการนำไปเผยแพร่ต่อสาธารณะ

ข้อจำกัดการตรวจ: ทดสอบเกมใน Chromium ผ่าน HTML ที่รวมไฟล์เข้าหน้าโดยตรง (รวมภาพเป็น data URL เฉพาะการทดสอบ) ได้ทั้งจอ 1706, 1366 และ 760 px; sandbox จำกัดการเปิด file:// และ localhost จึงยังไม่ยืนยันการเปิดจาก Windows จริงด้วย START.bat
